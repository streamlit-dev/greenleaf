# GreenLeaf - Grocery Store Management System

Technology: Python, Flask, SQLite, HTML/CSS

**** How to Run **
1. pip install flask
2. python app.py
3. Open http://127.0.0.1:5000
4. Login: admin / admin123

** **Features**
- Login System
- Add, Edit, Delete, Search Products
- Billing with Automatic Stock Update
- Bill History with Total Sales
- Low Stock and Expired Alerts
